# 1.0.1：改善入口覆盖键盘时的轻点穿透

版本名 `1.0.1`，内部版本 `21`，包名 `dev.corner.bloom`。1.0.1 曾作为独立 APK 交付，签名证书与仓库 1.0.0 一致，可覆盖安装并保留本地设置。签名私钥不进入仓库。

## 修复

- 原先按压超过 350 毫秒，即使尚未达到系统长按阈值，也会被丢弃。现在遵循系统长按阈值；长按删除、滑动和多指取消仍分别处理。
- 原先在松手坐标补点，轻微偏移可能将回车等边缘按键的目标移到按键外。现在在最初按下的坐标补点，仍检查整个移动轨迹以排除滑动。
- 修改入口的透明度与触摸标志后，跨过两个显示帧再补点，并至少保留 32 毫秒让开时间，降低主线程繁忙时仅靠固定延迟产生的时序问题。该等待不能证明厂商输入系统已确认窗口更新。
- 补点按下时长从 24 毫秒调整为 48 毫秒。
- 仅在系统明确未接受手势请求时重试一次。已接受后取消、回调缺失及超时均不自动重放，避免重复回车或重复发送。未收到显示帧或服务断开时恢复入口，停止过期任务。

## 已完成的验证

完整 Android 35 编译、DEX 打包和 APK 签名验证通过。新旧安装包的签名证书 SHA-256 一致，内部版本从 20 升至 21，设置结构没有迁移。

主机端回归覆盖 400 毫秒按压、松手偏移、80 毫秒延迟显示帧、一次及持续拒绝、取消后不重复补点、回调缺失、显示帧缺失和息屏取消；同时检查无障碍服务、长按删除输入连接、窗口恢复、位置编辑、页面导航和图标处理。这些平台替身不模拟真实输入法或厂商输入系统。

## 真机复测

覆盖安装后重新打开应用；如果系统尚未重新连接无障碍服务，关闭再开启「角落绽放 · 点击穿透」。保持原入口位置与输入法设置，重点验证：

1. 正常与稍慢轻点回车键，连续输入时是否仍漏点。
2. 从入口上滑启动应用，以及标记后的长按删除是否正常。
3. 横竖屏切换、锁屏再解锁、键盘高度变化后是否正常。

尚未完成目标手机的真机验证，不能据主机检查断言所有输入法漏点已经消除。
