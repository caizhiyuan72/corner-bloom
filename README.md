# 角落绽放 · Corner Bloom

一个面向安卓单手操作的角落应用启动器。从角落上滑展开常用应用，滑到图标后松手打开。

**1.0.0 · 首个正式版本**　Android 8.0+ · 原生 Java + Canvas · 无需 Root

[下载安装包](https://github.com/caizhiyuan72/corner-bloom/raw/refs/heads/main/downloads/corner-bloom-1.0.0.apk) · [SHA-256 校验](downloads/SHA256SUMS)

## 功能

- **一划启动**：最多放置 15 个常用应用，支持搜索、选择和排序；没有选中图标时松手取消。
- **三种展开样式**：整齐网格、规整扇形、经典散开，默认网格。
- **独立调整图标大小**：60%–140%，展开范围只调整位置和间距；空间不足时限制范围，避免遮挡或越界。
- **统一圆角图标**：保留原图颜色与透明度，不额外添加白底和留白。
- **应用内拖动编辑**：在屏幕预览中拖动入口、交换图标位置，保存后生效；取消或离开编辑页会丢弃草稿。
- **简洁设置与页面动画**：分类设置、浅色/深色模式、连续的横向页面切换，支持进入中返回。
- **可调外观与手感**：局部雾效、入口位置和触发范围、动画与震动。
- **固定入口与键盘辅助**：入口不随键盘上移；可选轻点穿透和按住删除键连续删除。
- **两种入口模式**：普通悬浮窗，或通过无障碍服务显示入口。
- **后台功能**：可选开机启动、隐藏最近任务卡片；入口异常时有限重试，也可在首页或通知中手动恢复、停止。

## 开始使用

1. 安装 APK，打开「角落绽放」，在「常用应用」选择应用。
2. 进入「位置与排列」，拖动预览中的亮条调整入口，拖动图标交换位置，点击保存。
3. 按提示授予悬浮窗权限，打开首页「角落手势」开关。
4. 从入口亮条上滑，保持按住，滑到应用图标后松手打开。
5. 在「外观与手感」调整展开样式、图标大小、间距、雾效和震动。

### 无障碍入口与键盘辅助

相关选项位于「显示与穿透」，默认关闭，需要手动开启系统无障碍服务。

- **通过无障碍显示入口**：使用无障碍窗口显示入口，无需普通悬浮窗权限。可尝试用于系统将“正在其他应用的上层显示内容”通知开关锁灰的情况；具体提醒行为取决于系统。服务断开时暂停入口，恢复连接后重建。
- **轻点穿透**：在松手后向入口下方同一坐标补一次点击，会有少量延迟。
- **按住删除键连续删**：需要 Android 13+。先开启「轻点穿透」，再开启此选项并「标记键盘删除键」。在入口覆盖已标记删除键的位置按住，连续删字，松手停止继续发送删除。

长按辅助针对底部固定文字键盘与已标记的删除键，不是通用长按转发。更换键盘布局、高度、屏幕缩放或方向后需重新标记。数字/电话输入框、悬浮键盘、自定义编辑器及输入法组合输入的支持情况可能不同。

### 后台运行

「后台与启动」中可开启自启动和最近任务隐藏。系统后台限制可能阻止恢复，强行停止后需要手动打开应用。入口消失时可点首页「恢复入口」。系统手势区域可能与入口冲突，可调整入口位置。

## 权限与隐私

应用未声明网络权限，设置保存在手机本地。

普通悬浮窗权限用于显示入口和启动器；无障碍模式使用已连接服务的窗口。前台服务和运行通知提供状态、恢复与停止操作；开机广播仅用于可选自启动。

无障碍功能由用户手动启用，未请求读取窗口内容或触摸探索。轻点通过手势注入实现；长按删除通过输入编辑接口发送成对的删除键事件，不查询或保存输入文本。

## 构建

需要 JDK 17、Android SDK platform 35、build-tools 35.0.0。可用 Android Studio 打开项目，或使用 Gradle 8.9：

```bash
gradle :app:assembleDebug
```

项目未包含 Gradle wrapper。也可以使用独立构建脚本（另需 Python 3）：

```bash
export ANDROID_SDK_ROOT=/path/to/android-sdk
bash tools/build.sh
```

输出：`app/build/manual/corner-bloom-1.0.0.apk`。

只有 JRE 时可设置 `BLOOM_ECJ_JAR=/path/to/ecj.jar`；也可通过 `BLOOM_ANDROID_JAR` 和 `BLOOM_BUILD_TOOLS` 指定 SDK 文件位置。

仓库不包含签名私钥。独立脚本在本地生成开发密钥，Gradle 使用本机调试签名，自行构建的密钥与发布包不同。官方首版沿用测试版签名并递增内部版本号，可覆盖安装、保留设置。请保管自己的签名密钥；卸载会清除应用设置。
